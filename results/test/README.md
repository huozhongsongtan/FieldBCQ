# 测试集结果归档

本目录归档自 `E:\field\论文撰写\FieldSeg-15K_全球多区域田块实例分割研究内容.md` 中的测试集结果。测试集采用论文中的 `test.cache` 口径，共 2,000 张影像、21,190 个田块实例；DDFHAPD 测试集包含 83 张空标注影像，评价时应保留这些负样本。

## 命名和追溯说明

论文原文将完整方法命名为 `FieldBQC = PBAS + RBQC`。当前项目的验证集目录将 `BAS + Boundary Dice + MQC` 统一命名为 `A+B+C`，两者的组件命名和实验配置并未在现有材料中逐项证明等价。因此这里保留论文原名 `FieldBQC`，不把测试汇总直接改写成 `A+B+C`。

如果后续确认论文的 FieldBQC 权重就是当前 `model/abc/` 中的同一组权重，应补充对应的 checkpoint 哈希、配置文件和评估命令，再建立 `A+B+C` 到 `FieldBQC` 的映射。
