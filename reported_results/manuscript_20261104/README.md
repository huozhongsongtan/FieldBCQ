Legacy task 10 reports parameters, GFLOPs and timing in manuscript Section 3.3, using the measurement protocol in Section 2.6.2: baseline / FieldBCQ parameters 62.051 / 63.970 M, computation 297.03 / 305.34 GFLOPs, raw forward 9.953 / 10.311 ms, and prediction pipeline 14.275 / 14.354 ms on RTX 4090. Parameter counts include auxiliary training branches; evaluation-mode computation excludes the training-only boundary predictor. These are recorded values, not measurements from this synchronization.

[TABLE_NOTES.md](TABLE_NOTES.md) preserves the current table captions, supplementary notes, and the computational measurement protocol. The CSVs match the saved manuscript's displayed precision, including two decimal places for count MAE and four for score–IoU ECE. Signed differences in Table 5 retain the manuscript's precision and were calculated from unrounded evaluation results. CSV files do not preserve the Word tables' bold formatting.

CLI task IDs and output filenames retain their legacy names. For example, CLI `table6.csv` corresponds to manuscript Table 5; filenames in this snapshot use the current manuscript numbering with an underscore. Values retain the source tables' units and displayed rounding. See the manuscript for definitions.

The fixed test images have previously been explored, and all three sources occur in training and testing. This snapshot does not establish independent blind or source-held-out performance. `checkpoint_inventory.json` records checkpoint hashes and saved training arguments; it does not independently reconstruct historical evaluator versions or link checkpoints to raw metric records. A new evaluation must retain its own provenance.
