This snapshot does not establish independent blind or source-held-out performance. `checkpoint_inventory.json` records checkpoint hashes and saved training arguments; it does not independently reconstruct historical evaluator versions or link checkpoints to raw metric records. A new evaluation must retain its own provenance.
